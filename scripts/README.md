# Utility scripts

Run from **repository root** (`python scripts/...`).

| Script | Purpose |
|--------|---------|
| `smoke_spade.py` / `smoke_spade_aerial.py` | Quick SPADE forward checks |
| `smoke_gan_v2.py` | Pix2Pix smoke |
| `check_aerial_warp.py` | Visualize polar warp |
| `check_eval_weights.py` | SPADE checkpoint sanity |
| `relabel_cvusa.py` | Build v2 SegFormer labels (one-time dataset prep) |
| `prepare_data.py` | CVUSA path list helpers |
